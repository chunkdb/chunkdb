# Release Preview Issue Mapping

Target mapping for release-preview readiness:

- Issue `#3`: release-blocker, included in release-preview milestone
- Issue `#6`: post-preview, remains open unless Windows Native TLS is explicitly claimed fully supported

This mapping must match:

- `README.md` support matrix
- `docs/KNOWN_LIMITATIONS.md`
- release notes (`docs/releases/v0.1.1-alpha.md` or preview notes)

If repository permissions are unavailable in the current execution environment, apply these issue/milestone updates via GitHub UI before publishing the release preview.
