# chunkdb v0.1.1-alpha

Engineering alpha focused on stabilization, validation depth, and clearer public positioning.

## What This Alpha Includes

### Storage Model

- specialized chunk/grid hierarchy:
  - large chunk -> regular chunk -> block bitfield
- configurable geometry and bit width (`block_bits`)
- `fs_split_v1` backend:
  - directory per large chunk
  - `.chk` data image per regular chunk
  - `.wal` delta log per regular chunk

### Protocol and Runtime

- chunk-native command protocol over TCP
- commands:
  - `AUTH`, `PING`, `INFO`, `GET`, `SET`, `CHUNK`, `CHUNKBIN`, `QUIT`
- worker-pool server runtime with buffered parsing
- token authentication
- `CHUNKBIN` binary transfer path for chunk payload reads

### Durability and Recovery

- delta WAL + threshold checkpoint write path
- durability modes:
  - `relaxed`
  - `fsync-wal`
  - `fsync-checkpoint`
- recovery validation coverage includes:
  - kill-recovery scenarios for `fsync-wal` and `fsync-checkpoint`
  - WAL replay edge cases (truncated tails/headers)
  - long-run WAL growth + checkpoint cycle correctness

### Validation and Benchmarks

- stress coverage includes hot contention + eviction + repeated load/unload cycles
- direct storage-path benchmark (`chunkdb_bench`)
- server-path benchmark (`chunkdb_server_bench`) covering:
  - `PING`, `INFO`, `SET`, `GET`, `CHUNK`, `CHUNKBIN`, mixed read/write
- per-scenario latency percentiles (`p50`, `p95`, `p99`) in server benchmark output

## Current Limitations (Alpha)

- single backend only (`fs_split_v1`)
- no cross-chunk atomic transactions
- no replication/distributed durability
- no shared-writer multi-process mode by default
- Windows Native TLS is not yet guaranteed as fully supported
- durability guarantees are mode-dependent and below full ACID systems
- benchmark scope is workload-targeted, not a complete production matrix

## Benchmark Interpretation

Benchmark results describe `chunkdb` behavior under its chunk/grid workload model.
Any cross-system comparison should be scenario-specific, durability-matched, and reproducible.

## Scope Discipline

This release intentionally avoids major new feature areas and focuses on engineering quality for the current alpha architecture.
