- The version clock writes its next range of tokens on a separate thread once half a range is left below the durable ceiling, and a range now holds 65536 tokens instead of 16384, so writers no longer all wait for the clock record's file and directory syncs at the end of each range; a writer waits only when it reaches the ceiling before that write completes. `StoreRuntimeStats` adds `version_clock_extensions`, `version_clock_extension_us` and `version_clock_wait_us` (#144).
