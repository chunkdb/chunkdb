- New data directories, tables and standalone stores enable `commit_groups`: their manifests bind one commit owner scope and the directory or store holds an INACTIVE `chunkdb.groups.owner` root, so earlier builds refuse them; `ENABLE FEATURE 'commit_groups'` binds an existing directory and its tables, backups carry the owner root, restores bind restored tables to the destination directory, and `chunkdb_verify` checks the scopes and the root. No write uses commit groups yet (#136).
