- MIGRATE takes up to 64 steps separated by `;` on one table, or one shared grant target for grant-only steps, and records the whole text as one migration. Each step sees the preceding changes and needs its own rights. CREATE TABLE, ADD CHECK, DROP NULL and a narrowing ALTER COLUMN ... TYPE without USING can be only the first step, and DROP TABLE runs on its own. If a concurrent creator wins, CREATE TABLE IF NOT EXISTS continues with the remaining steps on that table. After a crash or an OUTCOME_UNKNOWN reply, restarting the writer completes the migration if its decision survived (#161)
