- MIGRATE takes several steps on one table separated by `;`, at most 64, applied as one unit under one migration decision: after a failure or a crash every step is applied or none is, and the ledger records the whole text as one migration. Each step sees what the steps before it changed and needs its own rights; CREATE TABLE, ADD CHECK, DROP NULL and a narrowing ALTER COLUMN ... TYPE can be only the first step, and steps on several tables and DROP TABLE stay migrations of their own (#161).
