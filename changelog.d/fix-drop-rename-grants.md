- DROP TABLE and ALTER TABLE ... RENAME TO change the grants on the table's name together with the table: with a users file holding such grants, including when the server runs with `--auth none`, the change is journaled in `chunkdb.migration.pending` as format version 2 before the directory move that commits it. A writer start syncs the parent directories of the move before completing the grant change, or discards the journal if the move did not take place. Before, a crash, a failed directory sync or a failed users write could leave the grants of a dropped table for a later table of the same name, or the grants of a renamed table on both names. A failure to write the grants after the move now makes the server refuse catalog statements until a restart completes the change, as after a decided migration; a build that knows only version 1 of the journal refuses a directory with a pending version-2 journal (#306).
