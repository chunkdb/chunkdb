- The WATCH CATALOG epoch and revision survive restarts with the directory feature `catalog_revision` (incompat bit `0x80`, enabled on new directories, effective from the next start after ENABLE FEATURE). The server marks `chunkdb.catalog` before admitting a catalog decision and records each decided statement's revision before publishing it. `WATCH CATALOG AFTER epoch revision` resumes at a position the server holds, otherwise it sends `resync` and the whole catalog. Progress or a later visible change advances the watch past revisions with no visible changes. A crash with the record marked or a restart with changed user records or default feed and slot byte limits invalidates the old position. Backups leave the record out, so a restored directory starts a new epoch, and `chunkdb_verify` checks the record (#146).
